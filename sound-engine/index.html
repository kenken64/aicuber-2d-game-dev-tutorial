04 / PUT IT IN YOUR GAME

Bring the sounds into Godot.

Use the downloaded files in a local Godot project or your cloud workspace.

  1. Download the music track and the three WAV effects. Copy them into your project’s assets/audio folder (or upload them using Files in the cloud workspace), then wait for Godot to import them.
  2. Add an AudioStreamPlayer named Music to your main scene. Assign the music file to Stream and enable Autoplay. Enable looping on the imported audio resource if you want continuous music.
  3. Add AudioStreamPlayer children named JumpSound, CoinSound and SwordSound to the node that controls each action. Assign the matching WAV file to each Stream.
  4. In the script that owns each sound player, call its play() method when that action happens. For example, after a successful jump use $JumpSound.play(); call $CoinSound.play() when collecting a coin and $SwordSound.play() when attacking. Adjust node paths if your scene is organised differently.
  5. Run the scene and test all four sounds. Use Godot’s Audio buses and volume controls to balance music against effects.
