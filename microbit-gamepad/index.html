MAKECODE / BLUETOOTH / YOUR GAME

Build a micro:bit Bluetooth gamepad.

Turn an ELECFREAKS Joystick:bit V2 into a wireless controller using MakeCode blocks and a PC receiver.

Open MakeCode ↗

Three parts, one controller

The Joystick:bit reads the controls, Bluetooth UART sends their values, and a PC receiver translates them into keyboard or virtual controller input. Bluetooth pairing alone does not create a native gamepad.

01 / HARDWARE

Prepare the hardware

You need a micro:bit, Joystick:bit V2, two AAA batteries, a USB cable and a Bluetooth-capable computer. Insert the micro:bit into the board and install the batteries.

02 / MAKECODE

Create the block program

  1. Open MakeCode and create a project named Bluetooth Gamepad.
  2. Choose Extensions and add the official Bluetooth extension. Remove the Radio extension if MakeCode reports a conflict.
  3. Switch to JavaScript, replace the existing code with the program below, then switch back to Blocks to see and edit the generated blocks.
  4. Download the program to the micro:bit over USB, then power the controller with batteries.
MAKECODE JAVASCRIPT
let x = 0
let y = 0
let c = 0
let d = 0
let e = 0
let f = 0

bluetooth.startUartService()
basic.showIcon(IconNames.Happy)

basic.forever(function () {
    x = pins.analogReadPin(AnalogPin.P1)
    y = pins.analogReadPin(AnalogPin.P2)

    pins.setPull(DigitalPin.P12, PinPullMode.PullUp)
    pins.setPull(DigitalPin.P13, PinPullMode.PullUp)
    pins.setPull(DigitalPin.P14, PinPullMode.PullUp)
    pins.setPull(DigitalPin.P15, PinPullMode.PullUp)

    c = pins.digitalReadPin(DigitalPin.P12)
    d = pins.digitalReadPin(DigitalPin.P13)
    e = pins.digitalReadPin(DigitalPin.P14)
    f = pins.digitalReadPin(DigitalPin.P15)

    bluetooth.uartWriteLine(
        "" + x + "," + y + "," +
        c + "," + d + "," + e + "," + f
    )
    basic.pause(50)
})

On start, the program starts Bluetooth UART and shows a happy face. Forever, it reads both axes and all four buttons, sends a line of values, and pauses 50 ms—about 20 updates per second. It assumes active-low buttons (0 when pressed); verify this on your board.

03 / CONNECT

Connect to your PC

Pair using the micro:bit Bluetooth pairing procedure appropriate to your MakeCode Bluetooth settings. A separate PC receiver must connect to the Bluetooth UART service, subscribe to notifications and assemble complete newline-delimited messages before interpreting them.

512,510,1,1,1,1Example: a roughly centered stick and four released buttons. Actual center values vary.

Check each axis and button on your board. Calibrate the center and directions and use a dead zone so small variations do not move the player. Release any held controls if the receiver disconnects.

04 / NEXT STEP

Choose a PC receiver

Keyboard emulator

Map the joystick to WASD or arrow keys and buttons to Space, Enter or other keys. This is usually the easier first project.

Virtual gamepad

Map the values to a virtual Xbox or standard controller for games that require gamepad input. This needs additional OS-specific software.

A receiver is a separate application for Windows, macOS or Linux; this lesson does not install one. Choose your operating system and input mode before building it.
