01

Start your cloud workspace

Select Start cloud editor above. The server prepares a private Godot workspace with the starter project and opens it here. First-time setup can take about 20 minutes. When ready, select Launch cloud editor to open it in a new tab.

The 83 MiB starter ZIP is available if you want a separate backup. You do not need to upload it to the cloud editor.

02

Find the 2D workspace

Godot opens the starter project directly. Choose 2D at the top. The canvas is in the center, with project panels around it.

03

Read the Scene panel

Open res://scenes/Main.tscn in FileSystem. The Scene panel lists its nodes. Select Welcome to inspect the Label in the starter scene.

04

Explore the lesson assets

In FileSystem, open res://assets. The art is grouped by lesson module, ready to use in your final game.

05

Change the welcome text

Select Welcome in Scene, then edit its Text property in Inspector. Save with Ctrl+S (Cmd+S on Mac); the project files stay in your server workspace.

06

Run, back up, and stop

Press F5 or the Play button to run the project. When done, use Download my project ZIP for a copy, then Stop and delete workspace. Confirm the warning and wait for cleanup to finish.

You are ready to use these assets in Final Game.

PERMANENT DELETION

Delete your cloud workspace?

This will permanently delete your Lightsail instance and all saved project files.

  • Your Godot editor instance
  • All project files saved on the instance
  • Its static IP and subdomain DNS record

This cannot be undone. Download your project ZIP before continuing.
