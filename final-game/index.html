CAPSTONE / GODOT PROJECT

Build your final game.

Build one complete 2D level in the Godot cloud editor, using the characters, art, and systems you made across modules 1–18.

The one-level challenge

Create a single journey: start in a safe area, cross a hazard, collect 20 coins, visit a shop, defeat two enemy types and a boss, then make a final choice and reach the credits. Use the same level for solo, local co-op, and online play.

Make the story and visual theme your own. Keep the full journey playable from start to finish before adding extra polish.

Your starter kit

The ZIP contains a Godot project, published lesson media, animation coordinate files, and an asset catalog. The project opens on a welcome scene that you will replace with your level.

Download starter ZIP

Your saved game assets

Characters, bosses, and asset sheets you generated are separate from the shared ZIP. Download your saved PNG and JSON files here, then add them to your Godot project.

Open it in Godot

  1. Open the Learn Godot Web Editor lesson and start your cloud workspace.
  2. The starter project and lesson assets are installed automatically.
  3. Follow the sections below in build order. Run the same level after each section.
  4. For your own PNG and JSON files, use the Files control at the top of the cloud workspace to upload them into assets/my-game, then return to Godot's FileSystem panel.

Your project stays on the server while the workspace exists. Stop and delete workspace removes it permanently, so download your project ZIP first.
