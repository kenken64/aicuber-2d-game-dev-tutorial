The one-level challenge

Create a single journey: explore a forest with coins, a shop, enemies and a boss, then reach the portal for the ending and credits. Coins and enemy defeats are optional. Use the same level for solo, local co-op, and online play.

Make the story and visual theme your own. Keep the full journey playable from start to finish before adding extra polish.

Open it in Godot

Choose one way to work. Both use Godot 4 and the same starter project.

Option 1 · Godot on your computer

  1. Download and extract the starter ZIP above. Install or open Godot 4 on your computer.
  2. In Godot's Project Manager, choose Import, select the extracted project.godot file, and open the project.
  3. To use your own PNG and JSON files, copy them into assets/my-game in the extracted project folder. Create the folder if needed, then check Godot's FileSystem panel.
Download starter ZIP Get Godot 4 ↗

Your local changes stay in the project folder on your computer. Back up that folder or make a ZIP when you finish.

Option 2 · Cloud workspace

  1. Open the Learn Godot Web Editor lesson and start your cloud workspace.
  2. The starter project and lesson assets are installed automatically.
  3. For your own PNG and JSON files, use the Files control at the top of the cloud workspace to upload them into assets/my-game, then return to Godot's FileSystem panel.
Open cloud editor lesson →

Your project stays on the server while the workspace exists. Stop and delete workspace removes it permanently, so download your project ZIP first.

Local and cloud projects do not sync automatically. To continue a cloud project locally, download its project ZIP from the cloud workspace, extract it, and import its project.godot file in Godot.
